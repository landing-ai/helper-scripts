## Overview
This "label assistant" script is designed for segmentation projects in LandingLens. Similar to the "label assistant" feature for LandingLens Object Detection models, this script leverages an **already trained segmentation model** (deployed as a cloud endpoint) to automatically generate segmentation masks for unlabeled images. By doing so, it accelerates your segmentation labeling process, allowing you to quickly expand your dataset without manual mask creation.

## Purpose
Automatically generate segmentation masks for unlabeled images using a trained model in LandingLens.
- **Benefits:**  
  - **Increased Labeling Speed:** Reduce manual effort by using predictions to pre-label images.
  - **Enhanced Accuracy:** Use a model tailored to your project, especially effective for rare objects that general pre-trained models might miss.
- **Usage Scenario:** This tool is ideal when the segmentation object is uncommon in generic image databases and might not be well-handled by standard auto-labeling tools.

## How to Use This Tool
1. **Initial Labeling:**  
   Upload 10 images into your LandingLens segmentation project, define the classes, and manually label these images.
2. **Train a Model:**  
   Use Fast & Easy (F&E) train or custom training—depending on the complexity of your objects—to quickly train a segmentation model.
3. **Deploy the Model:**  
   Deploy your trained model to a cloud endpoint.
4. **Update the Script:**  
   Open the script file and update the following variables with your project details:
   - `self.endpoint_id = "ENTER_YOUR_OWN_ENDPOINT_HERE"`
   - `self.api_key = "ENTER_YOUR_OWN_KEY_HERE"`
5. **Prepare Unlabeled Images:**  
   In the same directory as the script, create a folder named `images` and place your unlabeled images there.
6. **Run the Script:**  
   Execute the script in your Python environment.
7. **Output:**  
   Once run, the script generates a new folder named `dataset` in the same directory. Follow the instructions provided in [LandingAI's upload guide](https://support.landing.ai/docs/upload-labeled-images-seg) to complete the image upload process.

## Q&A
- **Q:** What is the difference between this tool and the "Smart Labeling" tool in LandingLens?  
  **A:** The ["Smart Labeling"](https://support.landing.ai/docs/segmentation?highlight=smart%20labeling) tool in Landinglens also auto-labels images using pre-trained models; however, it might not perform well for segmentation tasks involving rare objects that are not common in Internet images. This script leverages a model specifically trained on your dataset to generate more accurate segmentation masks, offering an additional option rather than replacing the Smart Labeling functionality.
